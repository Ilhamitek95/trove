# Official logo wordmark — drop the files here

Every page renders the official wordmark from this folder, with the typed
name as an automatic fallback while the files are missing. Drop in:

- `trove-wordmark.svg`        — CHARCOAL wordmark (used on cream/clay surfaces:
                                storefront header + footer, dashboards, account)
- `trove-wordmark-cream.svg`  — CREAM wordmark (used on the charcoal panels:
                                apply page, seller-mode sign-in)
- `trove-wordmark.png`        — optional PNG fallback, same artwork (only
                                needed if an SVG export isn't available)

Rules already respected by the markup: the wordmark is the lowercase "trove"
with the swash 'e', approved colourways only, no effects or stretching
(height is fixed, width auto), clear space around it.

Also wanted when available: the official favicon/app-icon artwork to replace
`docs/favicon.svg` and `docs/apple-touch-icon.png` (currently an interim
"t." lettermark).
